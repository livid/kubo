### 🔦 Highlights

#### Local JSON HTTP access logs (livid fork)

This fork adds opt-in local request-start and completion logs for the RPC API and HTTP gateway, with timing, sanitized parameters, HTTP byte counts, and private rotating files. See [local HTTP access logs](../http-access-log.md). Logging is disabled by default. To turn it off after enabling it, run the following commands and restart the daemon:

```sh
ipfs config --json API.AccessLog.Enabled false
ipfs config --json Gateway.AccessLog.Enabled false
```

#### FlatFS disk-usage recovery (livid fork)

This fork pins [livid/go-ds-flatfs](https://github.com/livid/go-ds-flatfs) with a fix for negative cached usage after garbage collection. A complete synchronized recount replaces unsigned wraparound in `ipfs repo stat` without restarting the daemon. See [FlatFS disk-usage recovery](../flatfs-disk-usage.md) for behavior and limits.
